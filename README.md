# Код-фриз экспресс

Новогодняя игра для техно 2ГИС: детектив-мурдоку в ретро-поезде Петербург → Рускеала.
Пять дел, по одному в день с 21 по 25 декабря 2026. Без персональных данных: герои — выдуманные архетипы.

## Запуск

```bash
bun install
bun run dev        # разработка
bun run test       # тесты: у каждого дела одно решение, оно находится логикой, виновный сходится с сюжетом
bun run build      # статическая сборка в dist/ (base "./" — открывается из любой папки)
bun run gen        # пересобрать расстановки и улики (src/story/solutions.ts)
```

## Параметры адреса

- `?preview` — все вагоны открыты (для проверки до 21 декабря).
- `?date=2026-12-23` — посмотреть игру «как в этот день».
- `?nointro` — без пролёта камеры.
- `?q=low|mid|high` — принудительное качество графики.

## Где что

- `src/puzzle/engine.ts` — правила мурдоку, решатели (полный перебор и «обеденная» логика), тексты улик.
- `src/story/cases.ts` — пять дел: планы вагонов, тексты, виновные, развязки.
- `src/story/heroes.ts` — герои.
- `src/story/solutions.ts` — сгенерировано `scripts/generate.ts`, руками не править.
- `src/world/` — 3D: бесконечный лес (`scenery.ts`), поезд (`train.ts`), небо и горы (`sky.ts`), снег, пар, Санта, финальная ёлка (`fx.ts`), сцена и камера (`world.ts`).
- `src/ui/` — интерфейс в тёмной премиальной теме 2ГИС: панель дела (`casePanel.ts`), шапка, лента вагонов, мини-карта, модалки (`hub.ts`).
- `src/state.ts` — прогресс в localStorage, открытие по датам.
