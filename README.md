# Код-фриз экспресс

Новогодняя игра для техно 2ГИС: детектив-мурдоку в ретро-поезде Петербург → Рускеала.
Пять дел, по одному в день с 21 по 25 декабря 2026. Без персональных данных: герои — выдуманные архетипы.

## Где посмотреть

- Сайт: https://olesiabositi-hub.github.io/holy_express/ (обновляется при каждом пуше в `main`). До 21 декабря вагоны закрыты — добавьте к адресу `#preview`, чтобы открыть все.

## Запуск

```bash
bun install
bun run dev        # разработка
bun run test       # тесты: у каждого дела одно решение, оно находится логикой, виновный сходится с сюжетом
bun run build      # статическая сборка в dist/ (base "./" — открывается из любой папки)
bun run gen        # пересобрать расстановки и улики (src/story/solutions.ts)
```

## Параметры адреса

- `?preview` — все вагоны открыты (для проверки до 21 декабря).
- `?date=2026-12-23` — посмотреть игру «как в этот день».
- `?nointro` — без пролёта камеры.
- `?q=low|mid|high` — принудительное качество графики.
- `?at=2450` — начать с нужного места маршрута (0 — Финляндский вокзал, 2450 — крепость Корела, 4400 — Ладожские шхеры, 4980 — Сортавала, 5600 — водопады, 6050 — мраморный каньон).
- `?fest=75` — праздничный полустанок сразу перед поездом (число — насколько впереди); `?deer` — стадо оленей сразу; `?aurora` — северное сияние сразу. Для проверки сцен.

## Где что

- `src/puzzle/engine.ts` — правила мурдоку, решатели (полный перебор и «обеденная» логика), тексты улик.
- `src/story/cases.ts` — пять дел: планы вагонов, тексты, виновные, развязки.
- `src/story/heroes.ts` — герои.
- `src/story/solutions.ts` — сгенерировано `scripts/generate.ts`, руками не править.
- `src/world/landmarks.ts` — реальные места маршрута и «путешествие»: где поезд сейчас, что показывать рядом, где расчищать лес.
- `src/world/` — 3D: бесконечный лес (`scenery.ts`), поезд (`train.ts`), небо и горы (`sky.ts`), снег, пар, Санта, финальная ёлка (`fx.ts`), сцена и камера (`world.ts`).
- `src/ui/caseScene.ts` — экран дела, механика как на murdoku.com: карточки подозреваемых, план с координатами, заметки тапом, установка удержанием, протяжка, крестики, ластик (удержать — стереть всё), отмена, пошаговые подсказки, «Проверить», таймер. `howto.ts` — обучение из 6 шагов и справка «Как играть». `ticket.ts` — билет из пяти частей.
- `src/ui/hub.ts` — шапка, лента вагонов, мини-карта, билет, модалки.
- `src/world/horizon.ts` — горизонт Карелии: лесистые холмы и гранитные скалы.
- `src/state.ts` — прогресс в localStorage, открытие по датам.
