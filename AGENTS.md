## Правила проекта
- Никаких реальных людей, имён и фактов о сотрудниках. Герои — выдуманные архетипы. Почему: игра внутренняя, но персональные данные использовать нельзя.
- Каждое дело обязано: иметь ровно одно решение, решаться `logicSolve` без перебора, давать сюжетного виновного. Проверяется `engine.test.ts`. После правки плана вагона или текста улик — `bun run gen`, затем `bun run test`. Почему: игроки решают за обедом, сломанная головоломка убивает игру.
- Улики — простым текстом, без кода и терминов, которые понятны только разработчикам. Шутки — для всех в IT.
- Снег идёт всю игру. Санта пролетает раз в 30–50 секунд, но не во время решения дела.
- Прогресс только в localStorage, без бэкенда.
- Без внешних CDN: шрифт Golos Text из @fontsource, текстуры рисуются на canvas.
- Дизайн интерфейса — тёмная премиальная тема 2ГИС (см. дизайн-гайд проекта).
- Сказочные события мира — по таймерам, не все сразу: олени раз в 35–65 с, сияние эпизодами по ~30 с раз в 45–95 с, падающие звёзды раз в 10–28 с, праздничный полустанок раз в два оборота полосы (~2 мин), у него поезд гудит (`audio.ts`, звук синтезируется, включается после первого клика).
- Реальные места маршрута (`landmarks.ts`): мир остаётся бесконечной полосой, поверх неё едет маршрут длиной ROUTE_TOTAL (~10 мин), места появляются по своей отметке `at`. Лес и столбы внутри места расчищаются шейдером (CLEAR-прямоугольники), постройки полосы (деревня, станции, озеро, полустанок) прячутся. В местах нет настоящих источников света: их появление не должно перекомпилировать шейдеры. Внешний вид мест сверен с открытыми описаниями (Финляндский вокзал: низкий корпус, 17 окон, башня с часами и шпилем, Н2-293 в стеклянном павильоне; Корела: Круглая башня на острове Вуоксы; каньон: мраморные скалы, лёд, подсветка как сияние).
